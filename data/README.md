# Data

This directory is for the fictional data used by BodhaFlow.

I will add the project data here when I build the synthetic financial-support environment. That data may include fictional customers, merchants, card transactions, transfers, and support cases.

I will create every record specifically for BodhaFlow. The project will not store, use, copy, or represent real customer data, financial data, employer data, or proprietary data.

The `synthetic` folder will hold the records used by the application, tests, and demonstrations.
