# Synthetic Data

This folder will hold the fictional records used by BodhaFlow.

When I add data here, it will be created only for this project and used for local development, tests, and demonstrations. The records will be internally consistent so that I can test realistic support scenarios without using real people, accounts, merchants, transactions, or transfers.

I will keep the data safe to include in the repository. It will not contain real personal information, financial information, employer information, secrets, or proprietary material.

I will define the data structure and add the first records when I begin building the synthetic environment and mock tools.
